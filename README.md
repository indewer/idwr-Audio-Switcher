# idwr Audio Switcher v0.1 b3

Стильный, быстрый и компактный плавающий виджет для мгновенного переключения аудиовыходов в Windows 11 в один клик.

**Автор:** @indewer (indewer@ya.ru)  
**Версия:** 0.1 b3  

## Возможности
1. **Выбор только нужных устройств**: Нажмите на шестеренку ⚙️ в заголовке виджета и отметьте галочками только те выходы, которыми вы пользуетесь (например, наушники и колонки). Все остальные (HDMI мониторов, лишние разъемы) скроются.
2. **Свои понятные имена**: Каждому устройству можно задать короткое имя прямо в настройках (например, «Наушники» вместо «Динамики (1MORE Spearhead VR)»).
3. **Мгновенное переключение**: Клик по карточке устройства моментально делает его выводом по умолчанию для системы, игр и мультимедиа.
4. **Статус «Активно»**: Текущий активный аудиовыход подсвечивается индиго-свечением и маркером «Активно».
5. **Закрепление поверх окон (📌)**: Кнопка-булавка в шапке включает режим «Поверх всех окон», чтобы виджет всегда был под рукой.
6. **Перетаскивание**: Зажмите левую кнопку мыши на шапке или фоне виджета и перетащите его в любое удобное место экрана. Виджет запоминает свою позицию.
7. **Сворачивание в трей**: Кнопка «─» или «✕» сворачивает виджет в системный трей (возле часов). Двойной клик по иконке в трее открывает его снова.
8. **Автозагрузка**: В настройках можно включить «Запускать при старте Windows».

## Запуск
* Дважды кликните по файлу `Запустить AudioSwitcher.bat` в корне или напрямую запустите:
  `AudioSwitcherWidget\publish\AudioSwitcherWidget.exe`
